# 有用的 GitHub 連結與說明

收集實用的 GitHub repositories，包含連結與用途說明。

## 格式

```markdown
### 專案名稱
- **URL:** https://github.com/...
- **用途:** 簡短說明
- **Stars:** N
- **備註:** 使用心得
```

### 應用 1：技能演化系統
- **靈感來自：** 《關於我轉生變成史萊姆這檔事》
- **核心概念：** 像史萊姆每吞噬一個東西就習得新技能，技能之間會融合、進化
- **功能亮點：**
  - 自動化知識庫（從歸檔工具變成語義搜尋）
  - RPG 遊戲化（每日任務、隨機事件、Mystery Box、Streak）
- **應用場景：** 個人 AI 助手能力擴展、自動化工作流程

---

### 應用 2：個人知識圖譜
- **結構：** Hub & Spoke（一個中心樞紐，周圍是分支）
- **功能亮點：**
  - 交叉引用（1,553 條）
  - 語義搜尋（用自然語言問問題，幾秒內找到答案）
  - AI 分身同時處理（16 個分身整理）
  - 即時歸檔（隨手丟給 AI，自動歸檔）
- **應用場景：** 知識管理、第二大腦、研究資料整理

---

### 應用 3：自我進化
- **核心概念：** AI 系統的自我優化與成長
- **功能亮點：**
  - 前期雕很久（個性檔案，安全事件、context 壓縮）
  - 每天凌晨自動備份、更新索引、搜尋社群新技能
  - 跨時間記憶統合（散落在不同天的碎片被串起來）
  - Heartbeat 進化（從只回 OK 到自動判斷要不要打擾）
- **應用場景：** OpenClaw 自我優化、自動化系統維運
